# Changelog - @vitoria-rodrigues/plugin-web

All notable changes to `@vitoria-rodrigues/plugin-web` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-03

### Added
- **Initial Enterprise Release**: Web Domain Plugin compliant with `agent-plugins.org` v1.0.0 and Google Antigravity (`agy`).
- **Autonomous Skills**: `browser-operator`, `browser-auditor`, `web-extractor`.
- **Key Capabilities**:
  - Sovereign launcher routing to @vitoria-rodrigues/mcp-playwright and @vitoria-rodrigues/mcp-firecrawl
  - Accessibility snapshot tree navigation
  - Developer pairing mode
- **Dual MCP Manifests**: Native `mcp.json` for Antigravity and `mcp_config.json` for Claude Code.
